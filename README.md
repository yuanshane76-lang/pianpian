# 纸研工作台

纸研工作台是一款中文、本地优先的论文阅读工具。

## 当前能力

- 导入本地 PDF；
- 按页提取文本并生成稳定的阅读块；
- 搜索、收藏和标签筛选文献；
- 编辑文献标题、作者、年份和标签；
- 删除文献时同步清理本机原始 PDF、解析资产和 AI 缓存；
- 在原始 PDF 上点击已识别的段落、图表和公式；
- 对论文按需生成中文概览；
- 对整段或划选句子生成中文翻译、段落摘要和上下文作用；
- 双击原文段落并行开始整段翻译与解释，结果分别查看；
- 连续滚动阅读 PDF，点击图表时使用图表理解而非正文翻译；
- 在译文中渲染公式，保留原文的数学结构；
- 集中查看正文中实际出现的学术词汇；
- 基于论文正文进行中文问答；
- 将分析结果按正文内容签名保存在本地。

首次打开时文献库为空，不包含示例论文或测试数据。

## 文献库管理

文献库以本地为中心，支持完整的增删改查：

- **新增**：点击“导入论文”，或将 PDF 拖入文献列表；
- **查询**：按标题、作者、年份或标签搜索，也可以按收藏、最近阅读和标签筛选；
- **修改**：选中文献后，在详情页点击“编辑信息”，维护标题、作者、年份和标签；
- **删除**：在详情页点击“删除文献”，确认后会同时移除文献索引、本地原始 PDF、MinerU 解析结果、图表资源、任务记录和这篇论文的 AI 缓存。

文献元数据保存在本地浏览器存储，原始 PDF 和 MinerU 资源在桌面版中保存在 Electron 用户数据目录，不会上传到 Git 仓库。

## 服务配置

桌面版可在“服务配置”中填写阿里云百炼或 DeepSeek 官方的 API Key，按需生成概览、翻译、段落摘要、上下文作用和问答。MinerU Token 独立加密保存，用于识别段落、图表、表格和公式。导入后先打开原始 PDF；首次云端上传需要确认，用户授权后续自动解析时，之后导入可以直接启动 MinerU。申请步骤见 [服务密钥配置](docs/服务密钥配置.md)。

每位使用者和开发者自行配置密钥。仓库、测试和交付压缩包不包含维护者的密钥、论文或文献库。

## 开发

需要 Node.js 24.x、npm 和 Git：

```powershell
cd D:\Desktop\grade4\workspace\zhiyan
npm ci
npm run desktop:dev
```

本机只使用上述正式目录。旧开发目录的历史和文件保存在工作区外的离线备份，迁移结果见 [工作区迁移验收](docs/工作区迁移验收.md)。

仅预览网页时运行 `npm run dev`；桌面原件存储、系统密钥存储和 MinerU 调用请在桌面模式下验证。

验证：

```powershell
npm run check
```

协作流程见 [CONTRIBUTING.md](CONTRIBUTING.md)，人类开发者和编码代理共同遵守 [AGENTS.md](AGENTS.md)。采用任务分支、PR 审查和自动检查的方式合入 `main`。

## Windows 免安装压缩包

当前交付方式是 Windows x64 免安装压缩包，不需要安装 Node.js，也不需要代码签名证书。

```powershell
npm run make:win
```

构建完成后，压缩包位于：

```text
out/make/zip/win32/x64/纸研工作台-win32-x64-0.3.0.zip
```

对方使用时：

1. 解压整个压缩包；
2. 打开解压目录中的 `Zhiyan.exe`；
3. 不要只复制 `Zhiyan.exe`，它需要同目录下的 Electron 运行文件；
4. 原始 PDF、解析结果、图表资源、论文元数据和分析缓存保存在 Windows 用户数据目录，不会写回压缩包目录。

这类压缩包适合内部交付和演示。未签名程序在 Windows 首次启动时可能出现安全提示，需要用户选择允许运行。

## 目录说明

- `src/domain/`：论文、阅读块和分析缓存的数据规则；
- `src/services/`：PDF 解析、本地存储和分析服务；
- `src/features/`：中文文献库和阅读器界面；
- `electron/`：桌面端安全入口；
- `tests/`：领域规则和服务测试；
- `docs/`：当前产品架构说明。

当前版本的桌面壳已经可以离线启动，页面资源通过 `zhiyan://app` 应用协议加载，原始 PDF、MinerU 解析结果和资源保存在桌面用户数据目录，论文索引与 AI 缓存保存在本地浏览器存储。后续再迁移索引与缓存到 SQLite。
