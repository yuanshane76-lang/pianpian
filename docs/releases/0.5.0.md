# 篇篇 0.5.0

- 新增**论文知识库**：按论文列表逐篇提取概念与方法知识条目，跨论文自动聚合为知识页面，每条论述保留原文锚点，点击跳回对应论文原位；新增论文解析完成后自动汇入，也可手动触发补提取。
- 知识库默认以**深空星图**呈现：论文是金色枢纽星群，概念与方法是发光星体，标题近似的概念以星座线相连；支持星体拖拽、名称显隐、显示选项面板（类型过滤、隐藏孤星、星体大小、疏密、斥力、向心引力、重置布局）与列表视图切换，并提供双向链接与反向链接。
- **文章架构思维导图**全面重做：正文按真实章节合并为少数大部分，模型提炼各部分语义标题、跨部分论证主线与两级要点树，装配与各部分限流并发生成；导图与正文并列显示（占用段落助手位置、独立宽度），双击段落自动切回助手，点击支撑点跳回原文。
- 架构生成协议升级为 `paper-wiki-v2`：支撑点锚点严格限制在本部分阅读块内，越界锚点按幻觉丢弃；近似重复支撑点本地合并。
- 知识提取缓存绑定独立协议 `library-wiki-v1`，不随思维导图协议演进失效；知识库数据持久化在本机。
- 修复打开架构面板时整图缩成一团的适配问题，以及选中星图节点的光环显示。

## 选择下载

- 推荐 `Pianpian-Setup-0.5.0-x64.exe`：安装一次，以后可在应用内检查更新。
- `Pianpian-0.5.0-x64.zip`：完整解压后双击 `Pianpian.exe`，后续更新需手动下载。

更新不会上传论文、对话或模型/MinerU 密钥。模型与 MinerU 服务仍由用户自行配置，真实服务使用可能消耗账号额度或产生费用。
