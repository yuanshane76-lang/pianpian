# 篇篇 0.4.0

- 新增「检查更新」：文献库底部与桌面菜单均可打开，检查 GitHub Releases 中的正式版本。
- 更新下载显示进度，安装前验证发布签名与文件哈希；下载完成不会自动退出，点击「重启并更新」才安装。
- Windows 安装版支持后续自动更新，ZIP 继续提供手动分发；旧 ZIP 用户需先下载安装版一次。
- 延用原有用户数据目录，保留论文、分组、单词表、阅读位置、对话和加密服务配置；重启更新前备份关键数据。
Windows 安装程序暂未使用商业代码签名证书，首次运行可能显示系统信誉提示。应用内更新使用独立 Ed25519 发布签名验证安装包；它不等于 Windows 商业代码签名。

## 选择下载

- 推荐 `Pianpian-Setup-0.4.0-x64.exe`：安装一次，以后在应用内检查更新。
- `Pianpian-0.4.0-x64.zip`：完整解压后双击 Pianpian.exe，更新需手动下载。

更新不上传论文、对话或模型/MinerU 密钥；用户仍需配置自己的模型与解析服务。
