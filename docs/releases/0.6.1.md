# 篇篇 0.6.1

- **导入失败提示可关闭**：文献库顶部的红色报错条新增 × 按钮，点击即消失；下次导入成功后也会自动清除，不再一直停留在界面上。
- **导入报错指明文件**：报错现在显示是哪个文件失败（如「导入失败 xxx.pdf：…」），批量导入时不再需要猜。
- **损坏/截断 PDF 提前给出可操作提示**：下载中断留下的不完整 PDF（缺少结尾结构）在解析前即被识别，直接提示「文件不完整或已损坏，常见原因是下载中断，请重新下载后再导入」，不再抛出英文的 `Invalid PDF structure.`。
- 演示文稿识别口径修正：PPT 另存为的 PDF 识别为 PPT 场景后，**左侧保持原生 PDF 阅读面**（坐标定位、划选照常），助手切换为「陪你读 PPT」形态（解释与问答），并支持在 PDF 阅读面上拖拽框选多段；不再强制切换为幻灯片画布。
- 本版本包含 0.5.0 与 0.6.0 的全部更新（多标签阅读、全局人话模式、pptx/ppt 导入、知识库星图等），从更早版本自动更新的用户一次性获得。

## 选择下载

- 推荐 `Pianpian-Setup-0.6.1-x64.exe`：安装一次，以后可在应用内检查更新。
- `Pianpian-0.6.1-x64.zip`：完整解压后双击 `Pianpian.exe`，后续更新需手动下载。

更新不会上传论文、对话或模型/MinerU 密钥。模型与 MinerU 服务仍由用户自行配置，真实服务使用可能消耗账号额度或产生费用。
