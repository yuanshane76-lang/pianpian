# 篇篇 0.6.0

- 阅读器新增**多标签**：可同时打开多篇论文，从文献库、知识库星图、研究助手引用或单词表跳转时自动聚焦已有标签或新建（上限 8 个）；标签显示标题与解析状态，支持单击切换、× / 中键 / 双击关闭，加号按钮前往文献库继续挑论文。每篇的阅读位置、架构面板开合独立保留。
- **人话模式升级为全局设置**：开关移到篇篇助手头部，翻译、解释、学术词汇之外，读图表与读公式同样以通俗表达生成；标准与人话的缓存互不覆盖。
- 新增 **pptx/ppt 导入**：演示文稿走 MinerU 转换后以幻灯片画布阅读——按幻灯片页分组，复用块坐标还原原始版面（文字与图片在真实位置，不重排），单击选中、双击发起段落理解，支持拖拽框选多段后交给助手翻译或解释。PPT 另存为的 PDF 会自动识别为幻灯片模式；原生 PDF 阅读面与坐标定位完全不受影响。
- 研究助手新增 **Semantic Scholar 相似论文兜底工具**：arXiv/Crossref 检索不到、来源限流或需要从当前论文扩展相关工作时自动降级调用；候选经确认后以元数据加入文献库。
- 知识库数据源与单篇思维导图解耦，按论文列表独立提取，新论文解析完成后自动汇入（也可手动触发）。

## 选择下载

- 推荐 `Pianpian-Setup-0.6.0-x64.exe`：安装一次，以后可在应用内检查更新。
- `Pianpian-0.6.0-x64.zip`：完整解压后双击 `Pianpian.exe`，后续更新需手动下载。

更新不会上传论文、对话或模型/MinerU 密钥。模型与 MinerU 服务仍由用户自行配置，真实服务使用可能消耗账号额度或产生费用。
