# 篇篇 0.4.2

- 研究助手可并行检索 arXiv 与 Crossref；确认 arXiv 论文后，下载并校验官方 PDF，保存到本机文献库并进入 MinerU 解析流程。Crossref 结果仍作为元数据条目，不会伪装成已下载的 PDF。
- PDF 导入采用候选校验、下载限制和持久化回执；重复导入会复用已有原件和文献记录。
- 修复 Windows 安装完成页启动失败：完成页直接启动安装目录中的 `Pianpian.exe`，不再依赖中文快捷方式路径；开始菜单与桌面快捷方式仍会创建。
- 应用内更新继续沿用原有用户数据目录，并在安装前验证更新签名和备份关键数据。

## 选择下载

- 推荐 `Pianpian-Setup-0.4.2-x64.exe`：安装一次，以后可在应用内检查更新。
- `Pianpian-0.4.2-x64.zip`：完整解压后双击 `Pianpian.exe`，后续更新需手动下载。

更新不会上传论文、对话或模型/MinerU 密钥。模型与 MinerU 服务仍由用户自行配置，真实服务使用可能消耗账号额度或产生费用。
