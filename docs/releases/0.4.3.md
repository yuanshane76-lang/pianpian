# 篇篇 0.4.3

- 研究助手支持 DeepSeek 原生联网搜索，并保留检索过程、来源和引用边界。
- 论文检索支持 arXiv 官方论文导入，确认候选后下载并校验官方 PDF，保存到本机并进入 MinerU 解析流程。
- 新增 Semantic Scholar 相似论文雷达，帮助从当前论文发现相关研究。
- 文献库支持删除自定义分组；论文导入、检索和分组操作继续保持本地数据边界。
- 阅读辅助新增祖母模式和公式解读，修复段落翻译、解释结果中的 Markdown 渲染和数学表达式显示。
- 修复严格模式首次引用在 React 开发模式初始化过程中被清除的问题。

## 选择下载

- 推荐 `Pianpian-Setup-0.4.3-x64.exe`：安装一次，以后可在应用内检查更新。
- `Pianpian-0.4.3-x64.zip`：完整解压后双击 `Pianpian.exe`，后续更新需手动下载。

更新不会上传论文、对话或模型/MinerU 密钥。模型与 MinerU 服务仍由用户自行配置，真实服务使用可能消耗账号额度或产生费用。
