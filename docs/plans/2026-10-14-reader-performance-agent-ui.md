# 阅读性能、研究对话与段落词汇实现计划

**目标：** 修复真实长论文首开时的窗口停顿，改善研究助手工具过程，支持回答引用定位，并统一双击后的词汇生成体验。

**边界：** 原 PDF 仍为唯一阅读面；稳定块 ID 为引用身份；现有四项双击请求、取消和缓存规则保留。只在隔离用户目录做真实论文验收，不删除正式文献库。

1. 首开性能：分别采样未配置、已配置模型时的主进程心跳、渲染长任务、文件读取和首屏绘制；防止隐藏研究页签启动 Pi，SDK 初始化放到后台工作线程；合并开发模式短时间重复原件读取。
2. 引用：由 Agent 运行时根据本轮工具实际返回的块解析 `[引用:blockId]`，输出完整引用协议；拒绝无来源、其他论文与不存在的引用。流式消息和完成消息共用安全 Markdown 引用按钮。
3. 工具 UI：使用紧凑过程行、状态图标、任务摘要与可展开详情；搜索、确认、文档展示独立结果，默认隐藏原始 JSON；保留键盘操作、停止和流式滚动。
4. 词汇：单击未生成时显示空态；双击自动四路生成；仅展示 AI 精选且有本段原文依据的词汇。空结果、进行中、失败重试、缓存和收藏各有明确状态。
5. 验证：失败测试证明上述规则；运行完整 `npm run check`；隔离 Electron 用 DEER 45 页、FINDEEPRESEARCH 25 页反复打开、返回、缩放和引用跳转，监测未响应事件。真实模型进行两到三轮工具对话及段落词汇验证，截图不包含密钥；最后重启并确认产品响应。
