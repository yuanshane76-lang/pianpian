# 英文论文辅助阅读：本次实现设计

日期：2026-10-04。目标用户：能理解中文专业内容，但阅读英文论文慢、容易卡在词汇和长句的人。

## 用户体验

导入后先打开完整原文，后台完成基础段落整理。MinerU 的增强解析独立运行，章节、图表与公式准备好后叠加到同一个 PDF 阅读面。等待时显示真实处理阶段和阅读建议；不冻结正文，不在处理完成后突然换页。

PDF 保持原始排版，MinerU 交互层按自然段提供点击目标。点击段落后，右侧提供：

1. 翻译整段：中文译文保留术语和引用。
2. 摘要与作用：短摘要说明“这一段讲什么”，上下文作用说明“为什么出现在这里、和前后段如何关联”。
3. 划选句子：保留整段上下文，单独翻译或解释选中的句子。

右侧采用“读懂这段 / 学术词汇”两个入口，避免摘要、问答和大量单词把翻译挤到看不见的位置。论文问答和阅读指南按需展开。

学术词汇在正文准备好后立即生成：先通过内置学术词表识别实际出现的词，提供中文释义、出现次数和原文例句；AI 阅读指南补充论文专有术语。每个词必须能在正文定位，不展示模型虚构的“本文词汇”。用户可搜索词汇并回到出现位置。

## 冷启动策略

| 时点 | 用户可以做什么 | 后台任务 |
|---|---|---|
| 原件保存完毕 | 打开 PDF、翻页、查看图表 | 本地正文整理 |
| 基础正文可用 | 按段落阅读；看到初步词汇 | 用户授权后进行 MinerU 解析 |
| 增强结构可用 | 查看章节、图表、公式 | AI 阅读指南由用户触发 |
| 选择段落并操作 | 获得中文理解帮助 | 仅请求当前段落与必要上下文 |
| 再次打开 | 恢复位置，复用已有结果 | 有未完成解析时继续查询 |

默认不做全文自动翻译。AI 阅读指南一次生成文章概览与重点术语；段落理解按需生成，复用缓存。加载时提供骨架占位与实际阶段文字，允许继续阅读和离开当前页。

## 架构和数据责任

- Electron 主进程：密钥解密、外部 API、原始 PDF 和解析资产的本地文件存储。
- 文档存储：以原件 SHA-256 标识文件；保存原件、解析任务和解析结果，写入采用原子操作。
- 文本与阅读领域：段落规范、选择范围、结果校验、词汇定位和缓存签名。
- React 阅读器：PDF 画布、MinerU 交互层、选中上下文、加载状态、图表预览与词汇导航。
- AI 服务：普通文本输出用于翻译和问答；结构化 JSON 用于段落摘要/作用与文章阅读指南。

段落结果绑定论文内容、段落内容和实际模型配置；重新解析、修改密钥或切换模型后，旧结果不覆盖当前内容。解析结果和原件不因模型更换而失效。

## 决策

| 选择 | 采用方式 | 原因 |
|---|---|---|
| 全文预翻译或按需翻译 | 按需翻译 | 缩短开始阅读时间，控制费用 |
| 原始 PDF 或仅展示解析文本 | 两种视图 | 图表、公式有可靠核对依据 |
| 所有词汇交给 AI 或先本地识别 | 本地先显示，AI 补充 | 没有网络时仍可得到词汇帮助 |
| 一个大加载状态或独立任务状态 | 分开原文、解析、AI 状态 | 某项失败不阻塞其他能力 |
| 渲染任意服务 HTML 或安全文本 | 安全文本/受限标记解析 | 展示上下标而不执行外部 HTML |

本次保留本地文献索引和 UI 状态存储，原件、解析任务及资产迁入独立文件存储。暂不为这次迭代增加数据库安装与迁移成本。

## 验收

用 Transformer 和 RAG 两篇真实论文测试：完整原文保存、MinerU 上传/解析、图表放大、整段和选句翻译、段落摘要与作用、集中词汇、全文依据问答、重启复用原件和阅读位置。模型或解析失败时显示可重试错误，不提供伪造结果。打包产物不携带用户论文和密钥。
