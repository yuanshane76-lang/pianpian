# 英文论文辅助阅读：本次实现设计

日期：2026-10-04，2026-10-10 更新。目标用户：能理解中文专业内容，但阅读英文论文慢、容易卡在词汇和长句的人。

## 用户体验

导入后先打开完整原文，后台完成基础段落整理。MinerU 的增强解析独立运行，章节、图表与公式准备好后叠加到同一个 PDF 阅读面。等待时显示真实处理阶段和阅读建议；不冻结正文，不在处理完成后突然换页。翻译、摘要、图表解读和词汇精选都在用户主动点击后生成，界面不预先准备全文译文。

PDF 保持原始排版，MinerU 交互层按自然段提供点击目标。点击段落后，右侧提供：

1. 翻译整段：中文译文保留术语和引用。
2. 摘要与作用：短摘要说明“这一段讲什么”，上下文作用说明“为什么出现在这里、和前后段如何关联”。
3. 划选句子：保留整段上下文，单独翻译或解释选中的句子。

右侧采用“读懂这段 / 学术词汇”两个入口，避免摘要、问答和大量单词把翻译挤到看不见的位置。论文问答和段落分析按需展开。选中句子或段落后可以点击“加入对话”，篇篇会把原文、论文标题、页码和段落身份追加到当前论文对话输入框，用户确认问题后再发送。“祖母模式”是段落理解旁的可选开关，开启后翻译、解释、摘要/作用和本段词汇使用极通俗、短句化的中文，先解释术语再给准确名称；它不修改原文，也不会自动改写已经生成的标准结果。

点击特定段落后，先通过内置学术词表识别该段实际出现的词，再由用户主动请求 AI 精选 3–8 个有助于理解本段的术语、研究方法、学术搭配或论证表达。每个词必须能在本段定位，不展示模型从全文拼出的词汇。用户可以把词加入右上角的个人单词表，跨论文搜索、标记掌握状态、删除，并回到原句来源。

## 冷启动策略

| 时点 | 用户可以做什么 | 后台任务 |
|---|---|---|
| 原件保存完毕 | 打开 PDF、翻页、查看图表 | 本地正文整理 |
| 基础正文可用 | 按段落阅读；看到本段初步词汇 | 用户授权后进行 MinerU 解析 |
| 增强结构可用 | 查看章节、图表、公式 | 段落词汇和阅读理解由用户触发 |
| 选择段落并操作 | 获得中文理解帮助 | 仅请求当前段落与必要上下文 |
| 再次打开 | 恢复位置，复用已有结果 | 有未完成解析时继续查询 |

默认不做全文自动翻译，也不在导入或解析后排队生成译文。翻译、段落摘要与作用、图表解读、段落词汇和问答均按需生成并复用缓存。加载时提供骨架占位与实际阶段文字，允许继续阅读和离开当前页。

## 架构和数据责任

- Electron 主进程：密钥解密、外部 API、原始 PDF 和解析资产的本地文件存储。
- 文档存储：以原件 SHA-256 标识文件；保存原件、解析任务和解析结果，写入采用原子操作。
- 文本与阅读领域：段落规范、选择范围、结果校验、词汇定位和缓存签名。
- React 阅读器：PDF 画布、MinerU 交互层、选中上下文、加载状态、图表预览与词汇导航。
- AI 服务：普通文本输出用于翻译、解释和问答；结构化 JSON 用于段落摘要/作用、图表解读和本段词汇精选。摘要和图表的部分字段逐步显示，只有完整、通过校验的结果进入缓存。

段落结果绑定论文内容、段落内容、实际模型配置和表达模式；重新解析、修改密钥或切换模型后，旧结果不覆盖当前内容。标准模式和祖母模式使用不同缓存身份。解析结果和原件不因模型更换而失效。

## 决策

| 选择 | 采用方式 | 原因 |
|---|---|---|
| 全文预翻译或按需翻译 | 按需翻译 | 缩短开始阅读时间，控制费用 |
| 原始 PDF 或仅展示解析文本 | 原始 PDF 是唯一阅读面 | 图表、公式有可靠核对依据 |
| 全文词汇或段落词汇 | 当前段落本地识别，AI 按需精选 | 词汇与阅读动作保持同一段落范围，避免全文噪声 |
| 一个大加载状态或独立任务状态 | 分开原文、解析、AI 状态 | 某项失败不阻塞其他能力 |
| 渲染任意服务 HTML 或安全文本 | 安全文本/受限标记解析 | 展示上下标而不执行外部 HTML |

本次保留本地文献索引和 UI 状态存储，原件、解析任务及资产迁入独立文件存储。暂不为这次迭代增加数据库安装与迁移成本。

## 验收

用 Transformer 和 RAG 两篇真实论文测试：完整原文保存、MinerU 上传/解析与失败重试、图表放大和流式解读、整段和选句翻译、段落摘要与作用、段落专属词汇、个人单词表、全文依据问答、重启复用原件和阅读位置。模型或解析失败时显示可重试错误，不提供伪造结果。打包产物不携带用户论文和密钥。
