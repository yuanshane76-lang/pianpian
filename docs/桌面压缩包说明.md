# 纸研工作台桌面压缩包说明

## 交付形式

当前采用 Windows x64 免安装压缩包：

```text
纸研工作台-win32-x64-0.3.0.zip
```

接收方解压后直接双击 `Zhiyan.exe` 即可使用，不需要安装 Node.js、Electron 或其他运行环境。

## 构建流程

在项目根目录执行：

```powershell
npm install
npm run check
npx electron-forge make --platform=win32 --arch=x64
```

产物路径：

```text
out/make/zip/win32/x64/纸研工作台-win32-x64-0.3.0.zip
```

如果当前网络无法访问 GitHub 的 Electron 运行时下载地址，可在本次 PowerShell 会话中使用镜像：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_CUSTOM_DIR = "{{ version }}"
npx electron-forge make --platform=win32 --arch=x64
```

## 接收方使用

1. 解压整个 ZIP；
2. 双击解压目录内的 `Zhiyan.exe`；
3. 保留解压目录中的所有文件，不要只单独复制 EXE；
4. Windows 首次运行未签名程序时，按系统提示选择允许运行。

## 数据位置

应用程序文件和用户数据分离。程序目录只包含运行所需文件；提取出的正文、论文元数据和分析缓存保存在 Electron 的用户数据目录中，因此移动或重新解压程序不会自动删除已有数据。

原始 PDF 会保存到当前 Windows 用户的数据目录。桌面版支持通过 MinerU 增强解析段落、图表、表格和公式，并通过百炼或 DeepSeek 按需生成中文翻译、段落摘要、上下文作用和论文问答。模型密钥使用 Electron 安全存储，压缩包不包含用户密钥。

## 预置研究技能

压缩包包含论文精读、文献检索与筛选、文献对比与笔记三个研究 Skill。无需另行下载或安装技能，在研究助手的“预置研究技能”入口即可选择；执行研究任务仍需配置自己的模型密钥。

技能清单和 `SKILL.md` 位于 `resources/app.asar` 中，程序只读取登记的预置文件。精读与笔记使用当前论文解析文本，公开检索目前返回 Crossref 元数据；多文献对比会区分全文、摘要和元数据证据。

解压后的预置技能验收可运行：

```powershell
node scripts/packaged-research-skills-e2e.cjs "<解压目录>\Zhiyan.exe"
```

该验收读取包内资源，用已打包的 Pi SDK 和本地合成模型验证技能加载，再以隔离用户目录启动中文壳；不调用真实模型或 MinerU。
