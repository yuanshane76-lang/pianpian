# 段落双击分析 Implementation Plan

**Goal:** 双击完整自然段并行生成翻译、解释、摘要与作用及本段精选词汇，移除全文概览模块。

**Architecture:** 扩展 `App.tsx` 现有段落请求组，按操作分别维护流式正文、状态与缓存。组件保留结果页签，仅负责展示；取消、稳定内容签名和服务配置版本仍由现有边界管理。

**Tech Stack:** React、TypeScript、Electron 安全 IPC、Vitest、Playwright Electron。
