# 研究助手历史与双模式会话实施计划

**目标：** 提供本地对话的新建、列表/内容搜索、重命名、删除与一键恢复；阅读器会话绑定论文，首页会话检索整个文献库及已发布的解析正文。

**架构：** Electron 拥有原子持久化、历史事件归并、会话恢复与受控正文读取；前端服务适配 IPC，界面只呈现当前范围的历史。恢复历史同时恢复模型上下文，不重放工具写入或过期审批。检索按需读取本机已完成解析，不将全库正文塞入模型提示。

**任务归属：** 本分支 `feat/conversation-history`；主要修改助手 runtime/tools/IPC、Pi 会话初始化、preload/main、助手服务/界面及 App 首页入口；不改变密钥、PDF 解析、文献删除和其他任务 worktree。

1. 先添加历史存储 CRUD、重启恢复、损坏保护、范围隔离与非法输入测试；实现 `electron/research-conversations.cjs`。
2. 测试并实现首页无当前论文、全库元数据/正文检索和按论文 ID 阅读；阅读器拒绝跨论文读取，正文仅来自当前已完成批次。
3. 测试并接入历史 IPC、运行事件持久化和 Pi 历史恢复；取消/切换不串会话，恢复不执行旧审批。
4. 增加历史面板、新建、检索、重命名、二次确认删除、一键恢复与错误重试；首页显式全库上下文，阅读器显式单篇上下文；同步架构。
5. 聚焦测试、全量 `npm run check`、隔离合成服务桌面交互与截图，报告构建/桌面/真实服务的验证边界。不得调用真实服务或接触用户密钥。

## 实施结果与验证（2026-10-16）

- 全库首版是本地关键词检索，不是向量语义检索；正文读取校验已发布解析任务与批次，引用使用论文和阅读块的组合身份跳回原始 PDF。未解析条目仅作元数据候选。
