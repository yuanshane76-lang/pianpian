# 可调三栏与论文目录实现记录

目标：阅读器两侧分隔线支持拖动调整三栏宽度，左栏使用标题层级目录。

## 范围与边界

- 从 `origin/main` 建立 `feat/reader-resizable-outline`，使用独立 worktree，保留正式 checkout 中其他任务的修改。
- `src/domain/documentBlocks.ts` 拥有目录层级规则与旧数据兼容；标题层级不参与稳定 ID 和内容签名。
- `electron/mineru.cjs` 在解析边界保留正整数 `text_level` 与 Markdown 标题层级，统一为 1–6。
- `ReaderView.tsx` 拥有宽度偏好、容器尺寸约束、拖动与键盘交互；CSS Grid 消费左右宽度。
- 不修改原始 PDF 渲染、坐标规范化、模型调用或密钥存储。
