# 服务密钥强制引导实施计划

**目标：** 桌面端读取配置后，当前模型服务或 MinerU 缺少密钥时自动进入服务配置，补齐并成功保存后才能进入工作区。浏览器预览不强制配置。

**范围：** 复用系统安全存储与既有 IPC；仅新增公开配置完整性规则、启动门禁、弹窗引导与回归验收。不自动验证远端密钥，不产生付费请求，不改变论文就绪状态。

1. 在 `src/domain/serviceSettings.ts` 统一判断当前选中模型与 MinerU 的配置完整性，测试二选一模型、缺失项与完整配置。
2. 在 `tests/app/serviceSetup.test.tsx` 添加自动弹窗、读取期间不误弹、遮罩/Esc/焦点约束、分步保存、切换模型、保存失败、重新打开及浏览器预览测试，先确认失败。
3. 在 `src/app/App.tsx` 根据已读取公开配置控制强制弹窗；`ServiceSettingsDialog.tsx` 展示缺失项、密钥申请帮助与分步保存反馈，补齐后关闭。读配置失败时提供重试，不把默认空配置当作真实配置。
4. 在 `src/app/index.css` 添加符合现有主题变量的引导状态样式，兼容小窗口与深色模式；同步架构和用户配置说明。
5. 执行聚焦测试与 `npm run check`；隔离桌面目录进行引导、保存、重启与缺失单项的截图验收；本轮不接触正式密钥或调用外部服务。

**保留边界：** 开工时已有的发布依赖修复与回归测试独立提交；压缩包验收脚本中衔接强制配置引导的交互随本任务提交。不纳入用户数据、密钥或打包产物。
