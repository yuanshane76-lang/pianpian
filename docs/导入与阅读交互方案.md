# 纸研工作台：导入与阅读交互方案

更新日期：2026-10-11
状态：已认可；单一 PDF 阅读面叠加 MinerU 交互层，段落为默认翻译单位，划选句子时翻译所选内容。

## 产品目标

用户选择 PDF 后先在文献库完成 MinerU 解析与坐标准备，完成后打开论文原文，在原始排版上点击段落、图表和公式，默认翻译整段，也能划选单句翻译。

核心规则：

- 段落是排版和默认翻译单位，用户也能划选句子翻译。
- 保存完整的原始 PDF，重启应用后仍可阅读。
- MinerU 结构解析与坐标准备是打开阅读的前置条件；AI 分析单独维护状态。
- 翻译必须产生真实译文。未配置模型时，引导配置，不返回原文作为译文。
- 图表和公式有原始 PDF 作为核对依据，解析失败时原件保留在本机，文献库提供重试。

## 一、导入入口

文献库为空时，主操作为“导入 PDF”，支持选择文件和拖拽；已有文献时，保留相同入口。

服务配置放在常驻设置入口，不要求用户先填写全部密钥才能导入。

用户选择文件后：

1. 检查文件能否打开；损坏、加密或不支持的文件显示具体原因和下一步操作。
2. 检查是否已经导入同一文件；重复时提供“打开已有论文”，不重复创建记录。
3. 将原始 PDF 复制到应用的本地文献目录，建立文献记录。
4. 显示保存和处理状态。保存失败时明确说明，不把论文标记为“已保存”。
5. 原文可打开后，自动进入阅读器，不增加单独的“导入成功”确认页。

“导入”表示将论文加入本地文献库，并在已配置时自动发送完整 PDF 到 MinerU。入口说明自动上传解析，详情说明账号额度使用。

## 二、先完成解析，再打开原文

导入后留在文献库，论文条目及详情显示处理状态：

> 正在上传 / 云端排队 / 已解析 60% 页面 / 正在下载并准备定位

处理完成前「打开阅读」禁用，不自动跳入阅读器。

处理按阶段完成：

| 任务 | 产物 | 失败后的行为 |
|---|---|---|
| 上传与解析 | 章节、段落、图表、表格和公式结构 | 留在文献库，显示错误并重试 |
| 结果与坐标准备 | 完整解析资产及所有块的有效 0–1 坐标 | 阅读入口保持锁定，继续下载或重新解析 |

没有 MinerU 密钥时保存原始 PDF 和文献记录，提示配置服务，配置完成后自动继续解析。

MinerU 已配置时导入自动上传解析，文献库说明会上传完整 PDF 并使用账号额度。下载中断复用已有批次，不重复上传；成功上传后允许短暂的文件检测延迟，超过两分钟才提示重传。

不使用虚构百分比。状态显示实际阶段，例如“读取文件”“整理正文”“等待解析结果”“MinerU 交互层已叠加”。

## 三、正文整理完成后的进入方式

处理完成后，提示：

> PDF 已就绪，MinerU 交互层已叠加，可点击段落、图表和公式。

不再提供独立的阅读版和 PDF 版。阅读器始终以原始 PDF 画布作为唯一视觉底图，MinerU 只提供段落、图表、表格和公式的识别、点击、选中与定位能力。这样公式、双栏排版和图表始终以原件为准，不会因重新排版而错位。

论文标题优先使用可信的文档信息或正文识别结果；获取不到时使用文件名作为临时标题，支持修改。作者和年份缺失时不编造。

不提供独立全文概览模块。双击自然段同时生成译文、解释、摘要与作用及精选词汇，不作为“可以开始阅读”的前置条件；原文 Abstract 保留在 PDF 中阅读。

## 四、阅读器布局

桌面阅读器采用可收起的三栏：

| 区域 | 主要内容 |
|---|---|
| 左侧 | 章节目录、阅读进度；原始 PDF 视图下可切换页缩略图 |
| 中间 | 原始 PDF 画布；MinerU 识别出的段落、图表、表格和公式交互层 |
| 右侧 | 当前选中内容的翻译、解释，以及论文问答 |

顶部提供返回文献库、论文标题、视图切换、搜索、缩放和服务配置。

正文不展示 `p001-b001` 一类内部编号。使用章节、页码和自然正文帮助用户定位。

左侧和右侧均可收起，扩大阅读区域。长标题合理换行，不撑开页面。

## 五、句子选择与翻译

### 阅读与选择

PDF 仍保持原始排版，不把每一句做成独立的大卡片。MinerU 段落块只作为透明可点击层；鼠标悬停或选中时显示轻量边界和内容提示。

完整句子跨越 PDF 排版换行时，需要合并；英文断词、缩写、引用、公式和双栏顺序需要在正文整理阶段处理。标题、作者、脚注与正文分别处理，不混成一个长句。

用户点击一句：

1. 中间高亮这句，其他正文继续正常显示。
2. 右侧立即显示相同的选中原文及其页码。
3. 显示“翻译”“解释”操作。选择本身不发起收费请求。

用户拖选连续的几句，可按所选内容翻译；另提供“选择整段”，避免逐句重复操作。

### 翻译状态

| 状态 | 用户看到的内容与操作 |
|---|---|
| 未配置真实模型 | “配置翻译服务”，点击进入服务配置；阅读和选择继续可用 |
| 可以翻译 | “翻译成中文” |
| 正在翻译 | 选中内容旁显示“正在翻译”，正文仍可滚动和阅读 |
| 翻译成功 | 右侧原文下显示中文译文，支持复制、重新翻译 |
| 翻译失败 | 右侧显示具体错误与“重试”“检查服务配置” |
| 已有缓存 | 直接展示该句在当前模型配置下的缓存译文 |

翻译结果必须出现在用户刚操作的右侧区域，不能只写入已经滚走的正文位置。

可提供“在正文下方显示译文”的附加显示方式，默认以右侧展示为主。

切换句子或论文时，每个请求与原选中内容绑定。旧请求完成后，不覆盖新选中句子的显示内容。

右侧显示实际使用的服务和模型。演示功能与真实模型功能有明确标识。

## 六、图表与公式

原始 PDF 视图始终完整显示图表和公式。

统一 PDF 阅读器中：

- PDF 画布直接显示原始图表、表格和公式；
- MinerU 只负责识别这些元素并提供点击、说明和定位；
- 点击图表、表格或公式后，右侧显示对应内容的说明和原页信息；
- 解析未能准确识别边界时，仍以 PDF 原件为准，不生成错误的替代图表。

首版的交付要求是“能够清楚查看和核对图表”，不将 AI 解释图表作为查看图表的必要条件。

## 七、错误与恢复

| 情况 | 交互行为 |
|---|---|
| 文件损坏或无法打开 | 导入入口显示原因，提供重新选择；不留下看似正常的论文记录 |
| 本地文件保存失败 | 显示保存失败，提供重试；不声称重启后仍会保留 |
| 未配置 AI 密钥 | 原文阅读正常；在使用翻译、解释或问答时提供配置入口 |
| 未配置 MinerU | 阅读入口禁用，提供配置入口，配置后自动继续 |
| 云解析失败 | 原件保留在本机，文献库显示错误与重试入口，阅读保持锁定 |
| 模型请求失败 | 错误显示在对应任务附近，提供重试；不影响阅读 |
| 应用中途退出 | 已保存的原文保留；下次打开显示任务状态，允许继续或重试 |
| 旧论文只保存了提取文本 | 必须补齐原始 PDF 与 MinerU 解析结果；不能通过旧缓存状态绕过阅读门禁 |

## 八、首版验收

使用 Transformer 与 RAG 两篇测试论文验证以下行为：

1. 导入后在文献库显示进度；解析结果、资产与坐标全部就绪前禁止打开阅读，完成后可查看原始 PDF；重启后复用当前已发布结果。
2. 英文排版换行不会被当成独立句子，正文按自然段排版。
3. 点击句子时，中间高亮与右侧原文一致。
4. 未配置模型时能直接进入配置，不出现伪译文。
5. 配置模型后，点击翻译有明确反馈，译文显示在右侧；失败能重试。
6. 图表可放大，并能回到对应原始页。
7. 解析或模型任务进行中，用户仍能翻页、滚动和返回文献库。
8. 再次打开论文恢复阅读位置；切换选中句子不会显示其他句子的迟到结果。

推荐实现顺序：原始文件保存与 PDF 阅读 → 正文段落和句子整理 → 翻译交互 → 结构增强与图表嵌入 → 阅读位置和恢复。
