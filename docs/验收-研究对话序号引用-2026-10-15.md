# 研究对话序号引用验收

## 最终行为

- 回答只显示 `[1]`、`[2]` 等可点击引用序号，不附加来源页码、原文摘录或回答底部引用列表。
- 工具卡外不再附加一排来源按钮；读取工具的运行态摘要使用“读取论文原文”。
- 每条回答按首次实际显示的来源分配序号，同一块重复引用复用序号；增量流式期间保留已经显示的编号。
- 隐藏脚注不占用编号；代码、普通链接、伪造内部链接和不完整标记不变成可点击引用。
- 点击或通过 Enter 激活引用，定位到当前论文的稳定阅读块并高亮约 1.6 秒；恢复阅读位置不高亮。
- 页码、坐标和稳定块 ID 继续内部参与准确定位，Electron 引用协议和凭据处理不变。
