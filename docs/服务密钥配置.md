# 服务密钥配置

## 入口与安全边界

在 Windows 桌面版的文献库左下角或阅读器右上角点击“服务配置”。

- 配置页分为三个并列区域：**模型服务**、**论文解析**与**文献检索**；
- 模型服务在阿里云百炼和 DeepSeek 官方之间二选一，当前应用只使用选中的模型服务商；
- 论文解析单独使用 MinerU，负责段落、图表、表格、公式和坐标准备，不参与模型服务商选择；
- 密钥由使用者自己填写，仅保存在当前 Windows 用户的 Electron 数据目录；
- 主进程使用 Electron `safeStorage` 加密后写入 `service-settings.enc.json`；不提供明文存储降级；
- 前端只接收“已配置/未配置”状态，不回显保存过的密钥；输入框留空表示保留旧密钥，垃圾桶按钮表示删除；
- 浏览器预览不能保存密钥，也不能直接调用真实模型；
- ZIP 文件不包含使用者填写的密钥。密文依赖当前系统用户环境，不能当作可移植的密钥备份；
- 翻译、解释、摘要与作用、词汇、图表解读和研究 Agent 会将所需段落、上下文、图像或正文发送给当前选择的模型服务商，可能产生费用。未配置模型时不生成模拟回答，已就绪 PDF 仍可阅读。

## 阿里云百炼

1. 登录 [百炼控制台](https://bailian.console.aliyun.com/) 并开通所需服务；
2. 在控制台创建 API Key，检查账号额度与模型访问权限；
3. 在应用中选择“阿里云百炼”，填入 API Key 和模型名称，默认 `qwen-plus`；
4. 保存后可点击“测试所选模型”，它会发起一次很短的真实请求，可能产生少量费用；再用论文内容生成摘要验证。

请求固定走百炼官方兼容接口，不接受任意第三方 URL。

## DeepSeek 官方

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建新的 API Key；
2. 检查可用余额和模型权限；
3. 在应用中选择“DeepSeek 官方”，填入 API Key 和模型名称，默认 `deepseek-flash`；
4. 保存并测试所选模型，测试请求可能产生少量费用。

使用自己在官方平台创建的密钥。已在聊天、源码或文档中暴露的密钥应先撤销，再在应用中填写新的密钥。

## MinerU Token

MinerU 与模型服务分别配置。当前版本需要完成 MinerU 解析、资源持久化与全部阅读块的坐标准备，才能打开阅读器。不填写 Token 时可以先导入并保存原始 PDF，配置完成后自动继续解析。

1. 进入 [MinerU Token 管理页](https://mineru.net/apiManage/token)，注册或登录账号；
2. 按平台页面完成验证、开通或 API 使用申请；若没有创建 Token 的入口，先查看账号权限或提交平台要求的用途申请；
3. 创建或复制 Token，确认额度、有效期、计费规则；
4. 回到应用“服务配置”的 MinerU 区域填写，保存后检查“已保存”状态；
5. 遇到申请受限时，参考 [MinerU 官方 API 文档](https://mineru.net/apiManage/docs) 或联系平台支持。不要通过非官方代申请网站提交账号或密钥。

当前版本支持 MinerU v4 的 PDF 上传、任务轮询、结构化结果下载与本地保存。已配置 Token 时，导入 PDF 会自动上传到 MinerU，并可能消耗账号额度。Token 的有效性在实际解析请求中验证；设置页的检查按钮只确认 Token 已保存，不会额外上传论文。

问答最多提供正文开头 18 万字符；段落翻译、解释与摘要作用使用当前段落及附近上下文，划句分析只处理实际选中的原文；词汇精选只发送当前完整段落。图表解读发送选中图表的图像与相关上下文。超长论文的问答可能无法覆盖后半部分，不能将其视为全文审阅结论。

## Semantic Scholar 文献检索（可选）

阅读器的「相似论文」用 Semantic Scholar 的公开元数据接口查找候选，只读取标题、作者、年份、摘要和引用数，不下载全文，也不调用模型。

- **不填写也能用。** 请求进入公开的共享额度池，与全球匿名请求共用，高峰期可能返回限流；限流时会自动退避重试，仍失败则提示稍后重试。
- **填写后使用专属额度。** API Key 免费申请，填写后请求会带上它，检索更稳定；留空即继续使用公共池。
- 与其他密钥一样通过系统安全存储加密保存，前端只看到「已配置」状态，不回显密钥。
- 申请入口：<https://www.semanticscholar.org/product/api>。

**没有 DOI 的论文要走两步。** 雷达优先用 DOI 直接定位论文；没有 DOI 时先按标题检索、确认是哪一篇，再取相似结果。因此给导入的 PDF 补一个 DOI（文献库「编辑信息」中的 DOI 字段，可留空）能减少一半请求，也提高匹配准确度。无法确认身份时雷达会明确提示，不会给出可能不相干的候选。
