# 服务密钥配置

## 入口与安全边界

在 Windows 桌面版的文献库左下角或阅读器右上角点击“服务配置”。

- 密钥由使用者自己填写，仅保存在当前 Windows 用户的 Electron 数据目录；
- 主进程使用 Electron `safeStorage` 加密后写入 `service-settings.enc.json`；不提供明文存储降级；
- 前端只接收“已配置/未配置”状态，不回显保存过的密钥；输入框留空表示保留旧密钥，垃圾桶按钮表示删除；
- 浏览器预览不能保存密钥，也不能直接调用真实模型；
- ZIP 文件不包含使用者填写的密钥。密文依赖当前系统用户环境，不能当作可移植的密钥备份；
- 真实摘要、翻译、问答会将论文正文或相关段落发送给当前选择的服务商，可能产生费用。切换回“本地演示”则不联网。

## 阿里云百炼

1. 登录 [百炼控制台](https://bailian.console.aliyun.com/) 并开通所需服务；
2. 在控制台创建 API Key，检查账号额度与模型访问权限；
3. 在应用中选择“阿里云百炼”，填入 API Key 和模型名称，默认 `qwen-plus`；
4. 保存后可点击“测试所选模型”，它会发起一次很短的真实请求，可能产生少量费用；再用论文内容生成摘要验证。

请求固定走百炼官方兼容接口，不接受任意第三方 URL。

## DeepSeek 官方

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建新的 API Key；
2. 检查可用余额和模型权限；
3. 在应用中选择“DeepSeek 官方”，填入 API Key 和模型名称，默认 `deepseek-flash`；
4. 保存并测试所选模型，测试请求可能产生少量费用。

历史 PRD 中曾出现一条明文 DeepSeek Key，已从产品目录移除。请在官方平台撤销旧 Key，只在应用中填写新 Key。

## MinerU Token

MinerU 与模型服务独立，不填写也能用本地 PDF 文本解析。

1. 进入 [MinerU Token 管理页](https://mineru.net/apiManage/token)，注册或登录账号；
2. 按平台页面完成验证、开通或 API 使用申请；若没有创建 Token 的入口，先查看账号权限或提交平台要求的用途申请；
3. 创建或复制 Token，确认额度、有效期、计费规则；
4. 回到应用“服务配置”的 MinerU 区域填写，保存后检查“已保存”状态；
5. 遇到申请受限时，参考 [MinerU 官方 API 文档](https://mineru.net/apiManage/docs) 或联系平台支持。不要通过非官方代申请网站提交账号或密钥。

当前版本已经支持 MinerU v4 的 PDF 上传、任务轮询、结构化结果下载与本地保存。实际有效性在“MinerU 增强解析”时验证；设置页的检查按钮只确认 Token 已保存，不会额外上传论文。

真实模型调用会向所选服务商发送分析所需正文。摘要和问答最多取正文开头 18 万字符；翻译只取选中段落及其附近内容。超长论文可能无法覆盖后半部分，请勿把这些结果当作全文审阅结论。
